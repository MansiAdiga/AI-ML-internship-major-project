# Credit Card Fraud Detection using CTGAN

## 📌 Project Overview

This project uses Generative AI (CTGAN) to generate synthetic fraud samples and improve fraud detection performance on an imbalanced dataset.

## 🚀 Features

- Fraud detection using Machine Learning
- Synthetic data generation using CTGAN
- Random Forest classification
- Streamlit deployment
- Interactive prediction interface

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn
- CTGAN (SDV)
- Streamlit
